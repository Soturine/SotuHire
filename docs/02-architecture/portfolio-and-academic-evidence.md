# Portfólio e evidência acadêmica/profissional

apresentação, vídeo, áudio, escrita, arte, arquitetura, dados, eletrônica, hardware, acadêmico,
voluntariado e custom. Links são URLs validadas; anexos guardam metadata/hash, não execução.

tipados. Experiência, resultados, processos, treinamento, certificações, registros e voluntariado
seguem a mesma revisão. Resultados numéricos só entram quando confirmados.
