# Frontend v2

Routes finas consomem `features/career-copilot`. O Career Cockpit prioriza trajetória, atenção e
evidência em vez de cards financeiros. Evidence Inbox, Portfólio e Approval Queue são experiências
próprias. Copilot é drawer contextual persistente; Ctrl/Cmd+K busca rotas e dados locais.

Radix fornece focus management/Escape. Layouts cobrem 360–1920+, reduced motion e tema claro/
escuro. pt-BR/en-US cobre shell e experiências v2; telas históricas seguem migração incremental.
