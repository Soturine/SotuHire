# Sistema de ajuda

`ContextHelp` usa Radix Sheet e metadados compartilhados de rota. O botão `?` existe no shell, abre com foco contido, fecha com Esc e explica tela, uso, dados, IA, privacidade e limitações. `/help` pesquisa tópicos sem indexador externo.

O onboarding usa Radix Dialog, sete etapas, pode ser pulado e reiniciado nas preferências. Não cria dados nem chama provider. A extensão possui ajuda equivalente no popup.

Conteúdo de ajuda deve dizer o que a IA recebe, se a execução é local/externa, o fallback e o que depende de aprovação humana.
