# Auditoria final de produto — v2.0

O fluxo real implementado é: Evidência → graph → Career State → NBA → Copilot Plan/Proposal →
preview → aprovação → execução local → audit → undo → estado atualizado. Cockpit, drawer, Inbox,
Portfólio, fila e busca consomem a API v2; demo é identificável e fictício.

Limites honestos: MCP não foi exposto; criação/merge visual avançado de edges permanece API-first;
i18n completo cobre shell e superfícies v2, enquanto telas históricas ainda possuem trechos PT-BR;
portfolio export HTML/PDF ficou fora por não ser simples o suficiente para este gate. Extensão não
mudou funcionalmente e permanece 0.10.0.

O gate local final aprovou 661 testes backend, coverage 86%, 18 testes unitários web, build,
Chromium/Firefox/WebKit, auditorias npm/pip do projeto, secret scan, MkDocs strict, clean install,
ZIP 0.10.0 e SBOM 2.0.0. Providers foram exercitados uma vez: local íntegro, Gemini autenticado
com degradação em um schema após retry e OpenAI bloqueado por quota tipada.
