## Achados estruturais

- SQLite já é a fonte principal para snapshots, Application Lab, entrevistas, tarefas,
  taxonomias e inteligência de oportunidades; schema 8 é necessário para o núcleo v2.
- Perfil e alguns stores antigos ainda possuem compatibilidade JSON/JSONL. Eles não serão removidos
  sem migração comprovada; novos dados estruturados v2 terão somente SQLite como writer.
- Não havia Evidence Graph tipado, Portfolio persistente, Career State unificado, fila de aprovação,
  planos Copilot ou registry de tools com enforcement.
- A navegação e a Home ainda refletiam módulos v1. A reforma v2 deve preservar rotas compatíveis,
  mas apresentar a jornada Career Cockpit → evidências → propostas → aprovação.
- MCP não será exposto nesta release sem um transporte/token/scopes suficientemente isolado. O
  registry interno read/draft/write-local estabelece a boundary que um MCP futuro poderá consumir.
