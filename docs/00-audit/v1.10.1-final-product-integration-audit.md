# Auditoria final de integração do produto — v1.10.1

## Fluxo integrado

`Perfil → Career Context → currículo/material → fontes públicas → taxonomia → ranking → candidatura → entrevista/STAR/follow-up → tarefas/plano`.

## Source of truth

| Entidade | verdade e store | writer | readers / snapshot / dedupe | migração |
|---|---|---|---|---|
| Profile / ProfileItem | store local legado do Perfil | serviços de Perfil | Profile, contexto e análises; identidade/source_ref | legado ativo, sem segundo writer |
| CareerContext | contexto derivado do Perfil/escopo | context engine | tasks de IA; não é fato persistido novo | derivado |
| Resume | SQLite do Application Lab/Resume Studio | repository do Lab | Studio, Lab e snapshots; IDs de mestre/variante | vigente |
| ProfessionalAsset | repositório próprio | Professional Assets service | Lab/kit; fingerprint e dependency hash | vigente |
| Opportunity legado | `OpportunityStore` JSON para `ScrapedOpportunity` | pipeline legado | Radar/fontes antigas | legado ativo |
| Opportunity v7 | `opportunity_observations` SQLite | `CareerIntelligenceRepository` | API Intelligence; provider/external/url/hash | novo; contratos não têm writer duplo |
| Application | SQLite/application repository e snapshots | Tracker/Lab | Tracker, Intelligence | vigente |
| Interview / StarStory / FollowUp | tabelas SQLite v7 | `CareerWorkflowRepository` | rotas e web; IDs e vínculos | novo |
| Task / Reminder / CareerPlan | tabelas SQLite v7 | `CareerWorkflowRepository` | rotas, web e export ICS | novo |
| Taxonomy | cache imutável + manifest/mapping SQLite v7 | `VersionedTaxonomyStore` e repository | normalizer/API; hash e mapping_id | novo |
| ProviderRun | AiRun store redigido | tracing central | qualidade/diagnóstico | vigente |

Os contratos legado e v7 de Opportunity são deliberadamente distintos. Não há dual-write oculto. A conversão comum ocorre por adapter explícito; migração do histórico legado é trabalho futuro e não foi simulada nesta release.

## P0/P1 fechados

- pairing não devolve mais a prova no mesmo canal e usa origem exata da extensão;
- SSRF revalida DNS e redirects e bloqueia destinos não globais;
- erros de provider não expõem chave `AQ.`;
- registros profissionais não são certificados no JSON Resume;
- Dashboard não exibe scores inventados em API Real;
- novos domínios persistem no SQLite schema 7;
- follow-up permanece draft e ICS permanece download explícito.

## Estado de produto

Greenhouse, Lever, JobPosting, RSS/Atom, taxonomias e rankings possuem contratos de backend e testes. Interview, STAR, follow-up, tarefas, lembretes e plano possuem API Real e telas dedicadas. Idioma/tema/ajuda/onboarding são preferências locais e a extensão está em 0.10.0.

## Limitações aceitas

- conteúdo histórico de algumas telas permanece em PT-BR embora shell/navegação/ajuda e fluxos novos respondam ao locale;
- não há download automático de datasets oficiais nem redistribuição de bases sujeitas a licença;
- não há envio de e-mail, candidatura ou evento de calendário;
- não há migração automática de todos os stores JSON antigos para SQLite;
- conectores adicionais e busca global ficaram para o roadmap.
