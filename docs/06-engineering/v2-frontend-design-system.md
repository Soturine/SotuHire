# Design system v2

Identidade usa compass blue, evidence teal e superfícies de trajetória quentes. Tokens controlam
cor, spacing, radius, shadow, typography e motion. Cockpit não imita dashboard financeiro; visualiza
atenção, relações e progresso. Radix fornece dialog/sheet; reduced motion, dark/light, teclado,
touch targets e 200% zoom integram o gate.
