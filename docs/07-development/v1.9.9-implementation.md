# Implementação v1.9.9

A release integra o hardening antes planejado para uma versão intermediária e completa a jornada
documento→candidatura. Os principais limites de módulo são `modules/security`,
`modules/evidence`, `modules/application_lab`, `modules/professional_assets`,
`modules/parsers/document_ingestion`, `modules/storage` e as feature folders equivalentes no web.

Decisões centrais: schema SQLite 6 único; documento canônico compartilhado; bundle de análise
com motores independentes; lifecycle/stale persistido; API local segura por padrão; extensão
0.9.5 sem acesso a documentos locais; JSON legado preservado como compatibilidade/quarantine.

Validação completa e resultados ficam na [matriz de aceite](../09-testing/v1.9.9-acceptance-matrix.md)
e na [auditoria final](../00-audit/v1.9.9-final-integration-audit.md).
