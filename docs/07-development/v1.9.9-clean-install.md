# Clean install v1.9.9

O gate usa checkout limpo em diretório temporário dentro do workspace, dados sintéticos e portas
locais isoladas. Ele instala backend e frontend, inicia serviços, valida health, auth/pairing,
importa fixture, cria mestre e variante, exporta PDF/DOCX/JSON Resume, empacota/verifica a extensão,
encerra processos e remove apenas os dados temporários resolvidos dentro daquele diretório.

Comando automatizado de baseline:

```bash
python scripts/verify_clean_install.py
```

O roteiro v1.9.9 complementa esse script com as chamadas autenticadas de documento e export. Nenhum
banco ou currículo pessoal participa. Uma falha de instalação, pairing, export ou shutdown bloqueia
a release e é registrada na auditoria final.
