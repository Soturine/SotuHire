# v1.9.8 — Application Lab e Resume Studio

Esta entrega introduz uma orquestração persistente da candidatura e a fundação funcional do editor de currículos, sem duplicar engines de contexto, snapshots ou Tracker.

## Implementação

- migration 5: sessões, relatórios, sugestões, mestre/seções/entries, variantes/changes, templates/exports, kits/itens e planos/itens;
- domínio `modules/application_lab`: modelos Pydantic, repository SQLite, readiness determinístico, export e service;
- API: Lab e Studio com envelopes, paginação, validação e erros normalizados;
- web: dez etapas, estados reais, revisão individual, diff, kit, plano, Tracker, editor, preview e JSON Resume;
- extensão 0.9.4: captura/dedupe local e abertura do Lab por identificadores seguros;
- snapshots: vaga, mestre, variante, análise e kit vinculados à candidatura.

O score não é decidido por IA. GitHub pode ser N/A. O mestre não é mutado por variante. Nenhuma ação envia candidatura, documento ou dado a terceiros.

PDF/DOCX permanecem explicitamente pendentes para a v1.9.9. A entrega inclui preview e JSON Resume validado, não um sucesso simulado.
